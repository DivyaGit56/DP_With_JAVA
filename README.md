# 🚀 Dynamic Programming Repository

Welcome to my **Dynamic Programming (DP)** repository! This repository contains solutions to a wide range of Dynamic Programming problems implemented primarily in **Java**. It is designed to help students and programmers understand DP concepts from the basics to advanced interview-level problems.

---

## 📖 About

Dynamic Programming is an optimization technique used to solve problems by breaking them down into smaller overlapping subproblems and storing their results to avoid redundant computations.

This repository includes:

* ✅ Beginner-friendly DP problems
* ✅ Classic interview questions
* ✅ LeetCode, GeeksforGeeks, and Coding Ninjas problems
* ✅ Multiple DP patterns
* ✅ Well-commented Java solutions
* ✅ Time and Space Complexity analysis
